# ReBite — ولا لقمة تتلوح

**Live demo:** https://israairtirt.github.io/rebite/

Hackathon demo. Restaurants, cafés, bakeries and sweet shops in Tripoli post end-of-day surplus and cancelled orders at a discount; customers reserve nearby and pick up with a 4-digit code.

This is the browser-only build: everything runs in your browser and each device gets its own demo data. Open «وضع العرض» to see the customer app and the shop dashboard side by side.

This repo holds only the built site. The source is private.
